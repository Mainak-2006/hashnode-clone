## Day 12 — Deployment

### Backend — Render

`render.yaml` defines a Node web service rooted at `server/`:

- Build: `npm ci`
- Start: `npm start`
- Health check: `/api/health`
- `JWT_SECRET` generated by Render
- `MONGO_URI` and `CLIENT_URL` supplied as secret values

Required production environment:

```env
NODE_ENV=production
MONGO_URI=mongodb+srv://...
JWT_SECRET=<long random secret>
JWT_EXPIRES_IN=7d
CLIENT_URL=https://your-client.example.com
```

The API refuses to start in production without `JWT_SECRET`, accepts a comma-separated origin allowlist, and exposes `/api/health` for platform checks.

### Frontend — Vercel or Netlify

- `client/vercel.json` — build command, `dist` output, SPA rewrite
- `client/netlify.toml` — build command, `dist` publish directory, SPA redirect
- Set `VITE_API_URL=https://your-api.example.com/api` in the host's environment settings
- SPA rewrites ensure direct loads such as `/posts/my-slug` reach React instead of returning a host 404

### Post-deploy checklist

1. `GET /api/health` returns `{ "status": "ok", "database": "connected" }`
2. Register and log in on the live client
3. Publish a post and open it from the feed
4. Search, open a tag page, and view a profile
5. Confirm the private seed draft is absent everywhere public
6. Edit and delete the test post as its owner
7. Hard-refresh a deep link and confirm the SPA rewrite works
